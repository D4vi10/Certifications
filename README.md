# Certifications

Este repositório tem como objetivo documentar todos os certificados adquiridos ao longo da minha carreira profissional e simplificar o conteúdo descrito no curso de forma didática.
As certificações variam desde conteúdo da área de T.I. (Principalmente referente a segurança da informação) e cursos profissionalizantes para alavancar a minha carreira profissional.
